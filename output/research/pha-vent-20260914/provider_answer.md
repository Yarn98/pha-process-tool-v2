## 요약

잠정 권고는 일괄 승온이나 reverse element 추가보다, vent 역할·설비 이상·용융 상태를 먼저 분리 진단하는 것임. 현재 관찰은 용융 지연과 이송·충만도 문제에 모두 부합하나, 원인을 확정할 실측값은 없음. 실제 고분자 미용융이 확인되고 설비 이상이 배제된다면, 용융 구간과 탈기 구간의 기능 분리가 우선 설계 후보임. 초기 용융 구간의 가열은 조건부 시험 대상이나, 출구 온도가 같다는 이유만으로 안전하다고 판단할 수 없음. RPM 상승이나 처리량 감소로 vent 유출이 줄어도 MFR이 악화된다면, 이를 영구 운전조건으로 채택해서는 안 됨.

## 배경과 증거 수준

대상은 starve-fed co-rotating twin-screw compounder로 가정하였음. PHA grade·배합·스크류 도면은 알려지지 않았음. 아래 판단은 익명 시나리오에 대한 조건부 공학 검토임.

| 증거 수준 | 제공 내용 | 가능한 판단 |
|---|---|---|
| 정성적 사례 관찰 | 대기·진공 vent 유출, 덩어리, RPM·처리량 변경 후 MI 변화 | 진단 우선순위 설정 |
| 확인된 현장 실측 | 온도·압력·동력·수분·분자량·시험조건 없음 | 용융 부족·분해 원인 확정 불가 |
| 공학적 가설 | 용융 지연, 국부 과충만, 후단 저항, carryover | 구분 시험 필요 |
| 검증된 생산조건 | 없음 | 특정 온도·RPM·스크류 승인 불가 |

이하 MI/MFR은 MFR로 통일함. 기존 가이드는 제공된 설명 범위만 검토함. Web TARS 예측값은 실제 melt temperature나 PHA 분해속도의 대체값으로 사용하지 않음.

## 1. 대기 vent의 기능부터 분기

모든 vent에 완전 용융된 고분자가 도달해야 하는 것은 아님. ENTEK은 저벌크밀도 분말에 동반된 공기를 대기 vent로 배출하는 용도를 설명함. 이때 분말의 공기 동반 유출은 용융물 탈기와 구분해야 함.

| 기능 | 기대하는 상태 | 유출의 우선 해석 |
|---|---|---|
| 공급부 upstream/back-vent, 고체 탈기 | 고체 pellet·분말 존재 가능 | 공기 동반 분말 비산·공급부 과충만·이송 부족 |
| 대기압 용융 탈기 | 연속상 고분자의 용융과 노출된 melt surface | 용융 지연·국부 충만·insert carryover |
| 진공 용융 탈기 | 진공 격리용 seal과 부분 충만 구간 | backfilling·carryover·seal 불안정·가스 부하 |

용융 완료는 고분자 연속상을 뜻하며 filler 등 고체로 남아야 하는 성분까지 녹이라는 뜻이 아님. 두 vent 유출은 진공계통 단독 고장을 입증하지 않음. 공통 용융·이송 문제일 수도 있고, 대기 vent에서는 분말 비산·진공 vent에서는 melt carryover가 각각 발생할 수도 있음.

Coperion은 진공 vent 막힘과 목표 진공도 미달을 별도 문제로 구분함. 막힘 진단에는 insert, die·screen 저항, 스크류 배치와 마모가 포함됨. 진공도를 먼저 높이는 순서는 적절하지 않음.

## 2. 원인 우선순위와 조치

용융 지연과 이송·압력 제한을 공동 최우선 가설로 두되, 대기 vent가 고체 탈기용이고 배출물이 분말이면 순위가 달라짐. 순위는 발생확률이 아니라 현 패턴과의 정합성 기준임. 실제 점검은 비용·위험이 낮은 insert·제한부·온도제어 확인부터 진행함.

| 가설 | 부합 조건 | 데이터와 조치 | 가설을 약화하는 관찰 |
|---|---|---|---|
| 1A 불완전·지연 용융, 불균일 가열 | 덩어리가 고분자 잔류입자, RPM 증가로 용융·표면 갱신 개선 | 입자 정체·위치, heater·sensor·cooling 수정, 이후 용융 길이·혼합 기능 검토 | filler·이물 확인 또는 해당 melt vent 이전 용융 완료 검증 |
| 1B 이송·충만도/후단 압력 제한 | RPM 증가로 이송 여유, 후단 충만이 vent까지 확장 | 실제 Q·N, vent 인접 melt pressure, screen 차압·die 압력 동기화; 막힘·제한·마모 수정 | 적절한 압력·부분 충만이 반복 확인되는데 유출 지속 |
| 2 Insert carryover | 대량 역류보다 벽면 부착·회전 동반 배출 | OEM 형식·방향·간극·오염 확인·복구 | 적합한 insert인데 후단 압력 상승에만 연동 |
| 3 분말·고체 entrainment | 고체 탈기 위치, 가벼운 분말·저벌크밀도 원료 | 입도·조성, 공급 안정성·공기 경로·고체 취급 구조 | 균질 용융물이고 고체 유입 경로 없음 |
| 4 Melt seal 불안정 | 진공도·공급량·압력 맥동, 스크류 변경 후 발생 | 진공 절대압과 feed/압력 시간관계; 외부 누설·내부 seal 구분 | 외부 누설 배제, seal 안정, 유출·진공 변동 무관 |
| 5 수분·휘발분·분해가스 | 실제 수분 상승·발포·기포·응축물 증가 | 투입 직전 수분, 검증된 건조조건 비교, 필요 시 승인된 폐쇄계 가스 분석 | 수분·가스 개선 후에도 같은 압력성 유출·입자 지속 |

Coperion·ENTEK의 진단과 요소 이송/충만 길이 연구를 사례에 적용한 제안이며 현장 원인 확정이 아님.

덩어리에는 원료 pellet 잔류 core, filler 응집체, 이물, gel, 재고화 부착물이 포함될 수 있음. Vent 밖에서 식은 재료와 die 직후 입자를 구분해야 함. 현미경·분광·열분석을 원료 기준시료와 비교하되, **DSC에서 다시 녹는 사실만으로 압출기 안에서 한 번도 녹지 않았다고 판정할 수 없음.** 채취 위치·시점도 기록해야 함.

## 3. RPM·처리량·MFR의 상충

| 변화 | 유출 감소 경로 | MFR 상승 경로 | 판별값 |
|---|---|---|---|
| Q 고정, RPM 증가 | 회전당 투입 감소·이송 여유·표면 갱신·용융 개선 가능 | 변형률속도·점성 발열 증가; 체류 감소가 국부 열이력을 상쇄하지 못할 수 있음 | 입자, 실제 melt T, 순축동력, 압력, 동일 조건 MFR |
| RPM 고정, Q 감소 | 이송 구간 충만 감소 가능 | 동력이 Q만큼 감소하지 않으면 SME 증가, 충만 혼합부 노출 증가 가능 | 동력/Q, 온도, hold-up·RTD, MFR |

RPM을 높이면 체류가 짧으므로 안전하다는 결론도, RPM 때문에 기계적 사슬절단이라는 결론도 성립하지 않음. PC·PP 스크류 연구의 낮은 유량/긴 체류와 높은 유량/용융 부족 경계를 PHA 수치로 전용할 수 없음.

### Q/N과 SME

```text
m_rev [kg/rev] = Q [kg/h] / (60 × N [rev/min])
SME [kWh/kg] = Pnet [kW] / Q [kg/h]
t_mean,zone ≈ M_hold,zone / mass_flow_rate
```

Q/N은 회전당 질량의 비교 지표이며 무차원 충만도가 아님. 벌크/용융 밀도, 점도, slip, 마모, 압력 역류에 따라 관계가 바뀜. 같은 Q/N으로 국부 충만·온도·체류가 같다고 보지 않음.

Pnet은 무부하·구동손실을 적절히 보정해야 하며 모터 정격이나 torque %만으로 대체할 수 없음. Q 감소 비율보다 Pnet 감소 비율이 작으면 SME가 증가함. 충만 혼합부 보유질량이 유지되면 유량 감소가 구간 평균 체류를 늘리지만, 부분 충만 이송부는 보유질량도 감소할 수 있으므로 전체 체류를 Q만으로 단정하지 않음.

SME는 배럴 전열·국부 온도분포를 직접 포함하지 않음. Vent 유실이 크면 Q 정의와 물질수지가 흔들리므로 투입 기준 SME와 vent 유실량을 함께 기록해야 함.

### 냉각 pellet의 MFR

동일 시험에서 재현되는 MFR 상승은 직전 압출의 가역적 shear thinning만으로 설명할 수 없음.

| 구분 | 확인 | 한계 |
|---|---|---|
| 고분자 구조·분자량 변화 | SEC/GPC 이동·분포 | 분자량 저하를 확인해도 기계·열·가수분해 경로를 MFR만으로 구분할 수 없음 |
| 배합·수분 변화 | 선택적 vent 유실, filler/plasticizer, 투입·시험 전 수분 | 동일 recipe가 동일 최종 조성을 보장하지 않음 |
| 시험 이력·artifact | 건조, 온도·하중, 예열·대기, 절단 시점, 보관·장비 | 시험 중 변화가 압출 손상처럼 보일 수 있음 |

ISO 1133-2:2011 공개 설명은 시간–온도·수분 민감 재료의 가열시간·온도 관리와 시료 취급을 다룸. 평균·표준편차·반복 수를 같은 조건에서 비교해야 함.

| PHA 연구 | 확인된 범위 | 전용할 수 없는 결론 |
|---|---|---|
| Yamaguchi·Arakawa 2006, PHB, 180°C rheometry/GPC | 열이력에 따른 분자량·점도 저하, 외관 개선과 melt 유지력 저하 동반 | 외관 개선=품질 유지, 해당 온도=범용 PHA 설정값 |
| Leroy 등 2012, PHBV, 사출기 rheometry/SEC | 융점 부근 점도 저하·저분자화·oligomer 증가·가소화 가능성 | 융점 근처이면 안전, RPM에 의한 기계적 절단 확정 |
| Lajewski 등 2021, PHBV ENMAT Y1000P | 용융 상태와 시험 중 열이력이 rheology 해석에 영향 | 측정 가능 온도·점도모델=설비 안전온도·분해모델 |

위 연구는 익명 사례의 분해를 직접 확인한 결과가 아님.

## 4. 초기 가열과 출구 온도

초기 전열이 기계적 용융 일을 대체하면 출구 온도가 오르지 않을 가능성은 있음. 연화·용융을 앞당겨 점성 저항·후단 용융 부담과 순축동력이 낮아지는 에너지 수지 가설이며, 현 PHA에서 검증된 사실이 아님.

큰 유실·휘발 변화가 없는 정상상태의 개념식:

```text
mass_flow_rate × (h_out - h_in)
  ≈ Pnet + heat_barrel_to_resin - heat_loss
```

엔탈피에는 용융 에너지도 포함됨. 완전 용융과 잔류 고체 상태는 같은 평균온도에서도 엔탈피가 다를 수 있음. 설정온도 상승은 실제 가열 증가 대신 냉각 감소로 작용할 수도 있음.

| 지표 | 의미와 한계 |
|---|---|
| Barrel setpoint | 입력 목표값, 실제 배럴·수지온도 아님 |
| Actual barrel T | thermocouple 위치 값, 간극·재료 내부 국부온도 아님 |
| Local melt peak | 특정 위치·시간의 높은 수지온도, 출구평균과 다를 수 있음 |
| Exit melt T | 특정 측정점의 출구온도, 단면 평균·최고값 보장 없음 |
| Thermal history | 경험한 온도와 시간의 경로, 출구값으로 복원 불가 |
| Downstream cooling | 제거한 열, 분자량 손실 회복 아님 |

SPE의 Leistritz 발표 초록은 온도 probe의 대표성 한계를 설명함. 발표의 차이를 현 장비 보정값으로 쓰지 않으며 기존/OEM 승인 계측부를 사용함.

| 초기 가열 시험이 합리적인 조건 | 손상을 키울 수 있는 조건 |
|---|---|
| Heater·sensor·cooling 고장 배제 | 고장을 setpoint로 보상 |
| 고분자 잔류입자·늦은 용융 근거 | Filler·이물인데 계속 가열 |
| 입자와 순축동력이 함께 감소 | 국부고온·벽면 체류·용융 체류 증가 |
| 국부·출구 온도·MFR 기준 충족 | 출구 냉각으로 MFR 악화를 가림 |
| 공급부 냉각·고체 이송 유지 | 공급부까지 가열해 sticking·bridging |

후단 냉각으로 끊어진 사슬은 복원되지 않음. ENTEK의 2019 PP/talc 시험에서 후단 냉각 후 출구온도 감소와 압력 증가가 동반된 조건도 있었음. 냉각·압력 상충의 근거이며 PHA 설정값이 아님.

## 5. 기능별 스크류 검토

필요 위치에서 용융을 끝내고 vent 아래에 압력으로 재료가 차오르지 않도록 하는 것이 목표임. Kneading 존재가 충분한 용융 길이·갱신을 보장하지 않으며 reverse 제거만으로 열이력·충만 문제가 해결되지 않음. 기능은 형상·유량·점도·전후 압력에 의존함.

```text
주원료 공급·고체 이송
→ 선택: 고체 탈기용 upstream/back-vent (고체 존재 가능)
→ 제어된 용융 (필요 길이·표면 갱신·온도 균일화)
→ 선택: 대기압 용융 탈기 (용융 연속상·부분 충만)
→ 진공 격리에 필요한 최소 melt seal
→ 감압·부분 충만 forward conveying (vacuum vent)
→ 충분한 후단 이송·압력형성
→ 설치된 screen·die
```

최종 recipe가 아닌 기능 개념도임.

| 후보 | 기대 기능 | 검증·부작용 |
|---|---|---|
| 충분한 용융 길이와 분산된 갱신 | 집중된 강한 용융을 피하고 core 감소 | 고온 체류 증가 가능 |
| 적합한 forward·narrow-disc mixing | 이송·분할·재결합·열 균일화 | 필요한 분산응력 부족, 좁은 디스크만으로 저에너지 보장 없음 |
| 최소 안정 melt seal | 진공 격리·필요 충만 | 과도 제한은 상류 체류·발열·충만 길이 증가 |
| Vent 아래 압력 완화 이송 | 가스 통로·노출 표면 | 후단 압력이 높으면 충만 가능 |
| 후단 거리·pumping 능력 | Vent 이후에서 필요 토출압력 형성 | 거리만 늘려도 pumping 특성 부적합하면 실패 |
| 필요 시 vent 이동 | 용융 완료 후 melt vent | 후단 압력형성 길이가 줄어 전체 배치 재검토 |

Pro는 Leistritz 2023 전체 PDF를 확인하지 못했으며 검색 발췌의 narrow element 분배혼합 성격만 사용함. 특정 폭·각도·길이 근거로 사용하지 않음. Coperion은 vacuum vent 바로 아래 kneading 배치를 점검 대상으로 명시함.

제한 요소는 주로 상류 충만 영역을 확장하므로 같은 요소라도 위치에 따라 결과가 다름. Vent 상류에서는 용융·seal을 도울 수 있으나 이후 감압·이송 구간이 필요함. Vent 하류 제한의 상류 충만 영역이 vent까지 오면 flooding을 악화시킬 수 있음. 실제 충만 길이는 전체 압력 수지에 의존함.

Reverse block 하나 추가는 범용 처방이 아님. Seal 부족이 확인될 때 후보로 삼으며 기존 forward kneading·다른 압력 경계가 seal을 만들 수도 있음. 도면 없이 치수·각도·길이·개수를 승인할 근거 없음.

## 6. 최소 시험계획

안전한 기준조건이 없으면 운전 비교보다 정지 점검이 먼저임. Vent·screen·die는 OEM 절차에 따라 정지·격리/잠금표지·잔압/진공 해제·온도 상태 확인 후 점검함. 운전 중 vent에 봉·온도계 삽입 및 임의 개방 die 시험은 제외함.

| 고정 항목 | 기록할 판별값 |
|---|---|
| Lot·배합·공급 형태·실제 N/Q, 변경 대상 외 스크류·screen·die·진공·온도 | 입자 종류·빈도, 유출 형태·양, 투입·회수량 |
| 건조·보관·sampling·feeder calibration | 투입 직전 수분, 필요 시 시험 전 수분 |
| MFR 온도·하중·예열·절단·취급 | 평균·표준편차·반복 수, 필요 시 SEC/GPC |
| 승인된 계측 위치·방식 | 국부/출구 melt T, 배럴 실제값, heater/cooling, 순축동력 |
| 압력 위치·단위 | Vent 인접 melt pressure, screen 전후·die 압력, 진공 절대압 |

진공 절대압은 gas space 값이며 melt pressure·충만도 직접 측정값이 아님. 안정화 후 서로 다른 시점에서 시료를 채취함. Pro는 최소 screening의 독립 시간시료 3개 이상을 제안했으나 생산 승격의 통계적 충분성을 보장하지 않는다고 제한함. 허용 온도·압력·MFR·품질 범위는 사전에 정하며 새로 추정하지 않음.

| 단계 | 변경·유지 | 판별 | 채택·복귀 |
|---|---|---|---|
| 0 현상 분류·정지 점검 | 승온 없이 기능·insert·제한·마모·온도제어 확인 | 입자 정체·위치, 조립, 기존 이력 | 미용융이 아니면 승온 후순위; 이상이면 복구 우선 |
| 1 설비 이상 개별 복구 | 동일 규격 부품, 가능한 N/Q·열 유지 | 압력/차압·유출·입자·T·동력·MFR | 압력·유출 개선+품질 유지이면 원인 지지; 남는 증상은 다른 가설 유지 |
| 2 수분 비교, 이상 있을 때만 | 공급사 검증 건조범위, 나머지 유지 | Karl Fischer, 발포·기포·MFR·필요 시 SEC | 가스만 개선되면 수분 단독 원인 아님; 응집·품질 악화 복귀 |
| 3 초기 용융부 제한 가열 | 첫 비교에서 N/Q·후단 냉각 유지 | 입자·동력·국부/출구 T·압력·MFR | 입자/유출 감소와 T/MFR 기준 동시 충족; 과열/품질 악화 복귀 |
| 4 목표 기능을 특정한 스크류 시험 | OEM 검토, 용융·seal·이송 중 목표 특정 | 공통 지표, 필요 시 RTD/SEC, 목표 Q 안정성 | 품질 유지와 목표 Q에서 재현; 유출만 없어지면 실패 |

순축동력 감소도 단독 안전 근거가 아님. 후단 냉각은 별도 비교해 초기 가열 효과와 구분함. 안전한 A 조건이 있을 때만 A–B–A 복귀 비교를 하며 불안전·불합격 조건을 재현할 필요 없음. 단일 정상 측정으로 간헐 가설을 배제하지 않음.

## 7. 운전 조정과 재설계의 경계

| 확인 상황 | 결정 |
|---|---|
| Insert·screen/die·온도제어 고장 | 설비 복구 우선 |
| 설비 정상, 초기 용융 부족 근거 | 제한된 열 프로파일 비교 |
| 완전 용융을 위해 허용 열이력·품질 이탈 필요 | 용융 길이·갱신·제한을 포함한 재설계 |
| 용융 완료가 melt vent보다 뒤 | 앞당기는 설계 또는 vent 이동 |
| 후단 pressure build-up 부족으로 vent까지 충만 | 후단 pumping·제한·벤트 위치 함께 재검토 |
| RPM↑/Q↓에서만 유출 억제, MFR 악화 | 영구 조건에서 제외 |
| 용융·압력·seal 정상인데 잔여 carryover | 전용 탈기 부속/vent stuffer 적합성 평가 |

진공 강화는 용융 부족·후단 backfilling을 없애지 못하며 분말 흡인 동반을 키울 수 있음. Vent stuffer는 재료를 되돌려도 내부 압력·용융 상태를 자동 해결하지 않음. Coperion의 side-devolatilization 업그레이드는 모든 stuffer가 모든 원인에 적합하다는 근거가 아님.

## 8. 실제 결정을 좌우하는 미확인 데이터

스크류·배럴 도면 및 vent 역할, PHA grade·배합·투입 형태, 덩어리 정체·채취 위치/시점, 동기화된 N/Q·순축동력·압력·진공, 실제 배럴/melt T와 heater/cooling, 동일 조건 MFR·수분·필요 시 SEC/GPC, 목표 처리량·허용 품질이 필요함.

SEC/GPC는 용매·보정법·가용분 회수율, filler·불용분·oligomer 처리도 맞춰야 함. 분석 범위가 다르면 MFR 관계를 잘못 해석할 수 있음.

## Pro의 결론

현재 우선 행동은 vent 역할·덩어리 정체 확인과 insert·후단 제한·온도제어 이상 배제임. 설비 정상화 후에도 완전 용융과 부분 충만 탈기를 품질 범위 안에서 함께 확보하지 못하면 스크류 기능 재설계가 타당함. 초기 가열은 기계적 용융 일을 줄이는지 확인하는 제한 시험이며 유출 감소와 MFR·열이력 보존을 함께 확인해야 함.
