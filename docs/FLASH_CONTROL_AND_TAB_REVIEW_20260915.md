# 플래시 제어·탭 연결·싱글 파일 점검 — 2026-09-15

플래시 제어를 **위치 확인 → 발생 단계 비교 → 조건부 조치 → 제품 재검사** 순서로 바꿨습니다. 전문용어는 Claude 검수 뒤 풀이를 붙였고, 한 번에 모든 설정을 바꾸라는 안내와 실제 구현되지 않은 자동 제어 문구를 정리했습니다. 다른 탭에서 재현한 연결 오류도 수정했습니다.

## 현장에서 읽는 순서

1. **결함 알아보기:** 생성 이미지에서 정상 가장자리와 얇게 빠져나온 수지를 비교합니다. 금형 맞댐면·벤트·이젝터 중 위치를 고릅니다. 모르면 `아직 모름`을 유지합니다.
2. **발생 단계:** 충전만 한 제품과 보압까지 적용한 제품을 구분합니다. 아직 비교하지 않았다면 관찰부터 시작합니다.
3. **지금 확인할 순서:** 관찰에 맞는 점검, 조건이 맞을 때의 조치, 재검사, 중단·복귀 기준을 보여줍니다. 열화·과열 징후와 차가운 수지의 유동 저항은 별도 경로입니다.
4. **시험 체크리스트:** 기준 조건·이번 한 가지 변경·결과를 적고 파일로 저장하거나 공정 로그에 기록합니다. 언어·탭을 바꿔도 작성 중 내용은 유지됩니다.

8개 경로는 발생 단계 분리, 충전, 보압, 맞댐면, 벤트, 이젝터, 과열·열화, 유동 저항입니다. 각 경로에 출처와 적용 범위를 연결했습니다. 36개 캐비티·고정 승온 폭·보압비·벤트 깊이·형체력 20% 추가를 공통 처방으로 사용하지 않습니다.

## 조사와 Claude 반영

- [원문 조사와 범위](research/flash-control-evidence-20260915.md): BASF, RJG, ARBURG, ENGEL, MISUMI, CJ Biomaterials, Autodesk, Mold-Masters 등 13개 자료를 연결했습니다. 일반 사출 원리와 PHA 그레이드별 권고를 구분합니다. 직접 원문을 열지 못한 자료의 검색 발췌 범위도 표시했습니다.
- [Claude 용어 검수](research/claude-flash-terms-20260915.md)와 [가이드 전체의 쉬운 문장 검수](research/claude-flash-readability-20260915.md)를 실제로 받았습니다. 두 번째 검수는 21,106문자이며 생산 기록·API 키·비밀번호를 보내지 않았습니다.
- 제안 **25건 중 17건을 채택하고 8건은 기술적 뜻에 맞게 조정**했습니다. [항목별 반영 기록](research/claude-flash-readability-edits-20260915.json).

| 어려웠던 표현 | 반영 방향 |
|---|---|
| V/P 전환·캐비티 | 속도 제어에서 압력 제어로 바꾸는 시점, 제품이 만들어지는 금형 공간이라는 풀이 |
| 쇼트·공극·쿠션 | 미충전, 내부 빈 공간, 스크류 전진 한계까지 남은 거리로 구분 |
| 보압 후 발생 | 충전만 한 제품과 보압까지 적용한 제품의 비교임을 명시 |
| 틈 확대 | `틈 확대해 보기`로 관찰 버튼임을 표시 |
| P1/P2·MI | 두 보압 구간, 정해진 시험조건의 용융 흐름 지수라는 의미 보존 |

Claude는 문구를 검수했으며 원문 타당성이나 앱 동작을 검증한 주체는 아닙니다. 기존 2026-09-06 GPT-6 Pro 전체 가공 조사는 참고했지만, 이번 플래시 변경에 대해 새 Pro 답변을 받았다고 표기하지 않습니다.

## 새 이미지와 Blender 모형

정상/플래시 비교 이미지를 이미지 생성기로 새로 만들었습니다. [제작·해시 기록](research/flash-image-prompt-20260915.json). 제조사 슬라이드나 사용자 사진을 화면 자산으로 복제하지 않았습니다.

Blender에서 새 금형을 제작해 **정상·맞댐면·벤트·이젝터 4개 상태**를 내보냈습니다. 러너 → 게이트 → 캐비티 충전, 플래시 성장, 상부 금형 열기를 실제 GLB의 변형과 이동에 연결했습니다.

- `scripts/create_flash_mold_model.py`: 재제작 스크립트
- `art/flash-control/`: Blender 편집 원본·원본 렌더·제작 기록
- `assets/flash-control/`: 479,520바이트 GLB·4개 WebP 포스터·생성 비교 이미지
- `flash-mold-viewer.js`: 충전/보압 발생 예시, 정상 비교, 시점·동작 조작

금형 열기는 내부를 보는 조작이며 압력에 의한 실제 벌어짐이 아닙니다. 단계·플래시 두께는 설명을 위해 단순화·과장했습니다. 실측 불량이나 유동해석 결과로 사용하지 않습니다. WebGL 또는 GLB를 사용할 수 없으면 해당 위치의 Blender 이미지를 보여줍니다.

## 고친 연결 오류

| 화면 | 재현한 문제와 수정 |
|---|---|
| 공정 조건 | 참고 범위를 저장하면 작성 중 조건이 지워짐 → 같은 그레이드·공정의 입력 보존 |
| 이력 가져오기 | 쉼표·따옴표·여러 줄 CSV가 깨짐 → 인용 CSV/BOM 지원, 전체 검증 뒤 한 번에 반영 |
| 이력 가져오기 | 잘못된 JSON을 저장한 뒤 화면 오류 → 검증 실패 시 기존 기록 보존; 메타데이터·숫자 0 유지 |
| 기존 이력 | 이미 저장된 비정상 행/컨테이너에서 오류 → 원본 저장값을 바꾸지 않고 표시를 보호하고 복구 안내 |
| 이력 표시 | `<sample>` 같은 메모를 HTML로 해석 → 원문 텍스트로 표시 |
| 데이터 분석 | 숫자 기록 부족 시 선택기까지 사라지고 옛 그래프 잔류 → 선택기 유지, 그래프 정리·안내; 언어 전환 반영 |
| 물성 DB | 새로 가져온 재료를 선택할 수 없음 → 선택 목록 갱신 |
| 물성 DB | 삭제 뒤 편집기에 남은 값이 저장 시 부활 → 선택 재료의 편집 상태 갱신 |
| My AI | 첫 방문에서 직전 계산기 탭을 공정 탭으로 잘못 전달 → PC·모바일 공통 탭 전환 시점 추적 |
| 스트로 | 입력을 바꿔도 이전 생산량이 남음 → 재계산 안내로 교체, 입력·언어 보존 |
| 트러블슈팅 | 형상/설비 전환 뒤 키보드 초점 소실 → 새로 선택한 버튼으로 초점 복구 |
| 플래시 로그 | 빈 검색·삭제·숫자 0에서 이전 안내/그래프 잔류 → 현재 기록에 맞춰 갱신; 메모 HTML 해석 방지 |
| 배치 이벤트 | 언어 전환 시 미저장 메모 소실 → 해당 배치 안에서만 초안 보존 |
| 배치 이벤트 | 사출 mm/s를 rpm으로, 사출 bar를 토크율로 저장 → 실제 스크류 rpm을 별도로 입력하고 가짜 물리량 매핑 제거 |

상태 이벤트는 실제 회전수 입력이 필요하고 `0 rpm`도 유효합니다. 모르면 현장 메모로 기록할 수 있습니다. 사출 전진속도·압력은 기존 `process_snapshot`에 유지합니다. 이미 저장된 과거 이벤트를 자동 재해석하거나 덮어쓰지 않았으므로 과거 대체 매핑 값은 수집 당시 맥락을 확인해야 합니다.

## 로컬용 싱글 파일

[single-file/PHA-Process-Single.html](../single-file/PHA-Process-Single.html) 하나를 원하는 폴더에 받아 Chrome/Edge로 엽니다. 53,086,037바이트(50.63 MiB)이며 155자산·26 GLB를 포함합니다. 원본 폴더를 옆에 두거나 HTTP 서버를 켤 필요가 없습니다.

실제로 파일을 다른 폴더로 옮기고 이름을 바꾼 뒤 서버 종료·브라우저 오프라인 상태에서 검사했습니다. 계산, 기록 저장/재로드/CSV, 그래프, 한영 전환, 이미지와 사출·컴파운딩·Flash·벤트 3D가 작동했습니다. 각 이미지가 디코딩되는지와 GLB·JSON·라이선스 해시도 확인했습니다.

TARS/My AI 요청과 출처 링크는 해당 인터넷 서비스가 필요합니다. 글꼴은 시스템 대체 글꼴을 사용합니다. 파일 경로·브라우저·기기별 저장 영역이 다를 수 있으므로 이동 전에 기록을 내보내세요. 파일에 사용자 기록이나 개인 API 키는 포함하지 않습니다.

```powershell
npm run build:single
npm run test:single
```

소스가 바뀌면 `test:single`이 오래된 산출물을 거부합니다. 텍스트 LF 정규화로 Windows/Linux 체크아웃에서 같은 HTML·manifest를 생성하며 바이너리는 원래 바이트를 유지합니다. 파일 SHA-256: `b4080d8158bc46a93416a4302d16fb427f4c4214540b58c4986e46b83126b7c5`.
