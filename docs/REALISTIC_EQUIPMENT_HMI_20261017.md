# 실제 비율 설비·HMI·데이터 시각화 (2026-10-17)

브랜치 `feature/realistic-equipment-hmi`. 3D 설비를 실제 장비에 가깝게 다시 만들고, HMI형 입력 화면과 사람이 읽기 쉬운 도식을 추가했습니다. 반복해서 쓰는 도구(뷰어·Blender 부품·동작 메타데이터)는 공용 모듈로 정리했습니다.

치수와 동작은 두 조사 팩을 근거로 했습니다.

- Pack A: 사출기·HMI·시각화 규칙
- Pack B: 압출 라인과 이축 컴파운딩

두 팩 모두 GPT-6 Pro 조사 답변입니다. 구조화한 노트는 `output/research/pha-equipment-realism-20261017/`에 있습니다.

모든 치수는 등급 C(교육용 설계값)이며, OEM 도면도 PHA 운전 조건도 아닙니다. 브랜드 외형은 따르지 않았습니다.

## 공용 도구

| 파일 | 역할 |
|---|---|
| `machine-viewer.js` | 공용 three.js 스테이지를 제공합니다. 스튜디오 환경광, 그림자 맞춤, 클립 그룹화, 프레임 비용 거버너, 온도 오버레이, 사이클 스윔레인 차트가 들어 있습니다. |
| `scripts/pha_blender_kit.py` | Blender 부품·재질 라이브러리입니다. 단축 압출기(`single_screw_extruder`), 롤(`roll`: 베어링 블록·로터리 유니언 포함), 필름·시트 경로(`web`), 평다이(`flat_die`), 회전(`spin`), 경로 표시(`ride`, 물리 속도로 끊김 없이 반복)를 제공합니다. |
| `scripts/create_<kind>_motion.py` | 사출·컴파운딩·압출·시트·캐스트·블로운·블로우 성형 7개 설비를 실제 비율로 생성합니다. |
| `scripts/create_line_models.py` | 공용 조작 스키마를 제공하고, 모든 설비 메타데이터를 모아 `equipment-models.js`를 만듭니다. 스트로도 이후 `create_straw_motion.py`로 실제 비율로 다시 만들었습니다([사출기 수준 맞춤](INJECTION_LEVEL_LINES_20261017.md)). |

## 시각화

- **HMI 패널** (`hmi-panel.js`, 공정 조건 탭): ISA-101 방식으로 평상시는 중립색이고 범위 밖일 때만 색을 씁니다.
  - "입력값 · 실측 아님" 표시를 항상 붙입니다.
  - 개요 화면은 필드별 판독값과 참고 범위를 보여줍니다.
  - 온도 화면은 용융 측과 금형·롤 측을 서로 다른 축으로 그립니다.
  - 사출·보압 화면은 시간축 보압 단계, 사출압 상한(점선), V/P, 냉각 타이머를 그립니다. 충전 시간은 입력 항목이 없어 빗금으로 표시합니다.
- **3D 온도 지도** (사출): 배럴·노즐·금형에 입력한 설정값을 inferno 계열 순차색으로 칠합니다. 빗금은 미입력, 외곽선은 범위 밖입니다. 배럴 1이 호퍼 쪽인지 노즐 쪽인지 선택할 수 있습니다.
- **사이클 차트** (사출): 형체부·사출 유닛·스크류·금형·이젝터를 레인으로 나눕니다. 재생 위치가 3D와 같은 시각을 가리키고, 누르거나 끌면 그 시점으로 이동합니다.
- **트러블슈팅 판단 흐름** (`troubleshooting-tree.js`): 왼쪽은 공정별 증상 트리입니다. 오른쪽 흐름은 정지 기준 → 관찰·측정 → 원인 구분 → 원인 확인 여부 → 조치 → 재비교 → 재발 여부 순서입니다. 각 칸은 검토 KB의 문장을 그대로 옮깁니다.
- **그레이드 비교** (`grade-compare.js`, 물성 DB 탭): MFR은 시험 온도·하중별로 패널을 나눕니다. "<" 값은 상한 막대로 그립니다. 그 밖에 TDS 단계별 가공 온도 창과 건조 조건을 그립니다. 축이 서로 다른 값을 한 다각형에 겹치는 레이더 차트는 쓰지 않습니다.

## 검증

`npm run test:tools`가 추가되었습니다. 기존 검사는 새 설비에 맞게 바뀌었습니다.

`tests/blender-line-models.py`가 확인하는 항목:

- 스크류 나선과 회전 방향이 다이 쪽으로 이송하는지(컴파운딩 2날 요소와 사이드 피더 포함)
- 모든 닙·감김 방향과 같은 표면 속도
- 회전수 공식
- 버블의 BUR, 케이지 간극, 레이플랫 폭, 둘레 보존, 맥동 없음
- 블로우 성형의 시퀀스

웹 검사(`test:equipment`, `test:study`, `equipment-connections`)는 메타데이터의 비율·위치를 읽습니다.

소프트웨어 WebGL에서 실제 비율 GLB가 로드되는 데 시간이 걸려, 모델 준비 대기를 90 s로 늘렸습니다.
