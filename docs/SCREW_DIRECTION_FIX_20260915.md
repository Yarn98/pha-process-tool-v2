# 스크류 회전 방향 수정 — 2026-09-15

사용자가 컴파운딩 가이드의 스크류가 반대로 회전한다고 지적했습니다. 기존 나선 형상과 실제 Blender/GLB 회전값을 대조해 오류를 확인하고 수정했습니다.

## 원인과 수정

모형의 공급→다이 방향은 +X입니다. 양의 나선 기울기 `k`에 양의 회전 `phi`를 주고 있어, 고정된 관찰 각도에서 나선 마루는 `-phi/k` 방향으로 이동했습니다. 이 관계는 형상의 움직임을 검사하는 기하학적 기준이며, 수지 유속·토출량을 예측하는 식은 아닙니다.

- 일반 압출·시트·캐스트 필름·블로운 필름·압출 블로우 성형·컴파운딩의 스크류 회전을 반전했습니다. 컴파운딩 두 축은 같은 방향으로 회전합니다.
- 컴파운딩 사이드 피더도 주 배럴 쪽으로 이송되는 회전 방향을 적용했습니다.
- 새 벤트 가이드의 두 구성, 총 네 스크류에도 같은 오류가 있어 부호 메타데이터와 재생 경로를 수정했습니다. 역이송 요소는 같은 축에서 주 이송에 저항하는 형상으로 남습니다.
- 스트로는 반대 손잡이의 나선이어서 기존 방향이 맞습니다. Blender 원본과 GLB 해시를 유지했습니다. 사출 모형의 기존 방향도 맞습니다.
- 롤·절단기·수지 이동 표시 등 다른 동작은 유지했습니다. 기존 7개 라인의 정적 형상·재질·계층과 대상 외 애니메이션을 전후 비교했습니다.
