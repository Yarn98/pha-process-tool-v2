# PHA 사출 플래시·버 — 원문 근거와 조건부 점검 가이드

검토일: 2026-09-15. 적용 대상: 일반 열가소성 사출과 이 앱의 PHA/PLA계 컴파운드 사출. 원문이 특정 그레이드·장비·시험법에만 해당하면 따로 표시했다. 현장 시험 결과나 생산 설정값을 새로 만들지 않았다.

**표시할 핵심:** 플래시가 생긴 **위치**와 **충전·보압 중 발생 단계**를 먼저 나누고, 확인된 원인만 조정한다. 버가 없어져도 쇼트·기포·치수·물성이 나빠지면 채택하지 않는다.

짧은 한영 첫 문구:

- KO: **어디에, 언제 생겼나요?** 금형 틈새를 먼저 확인하고, 충전 중인지 보압 중인지 나눠 조치하세요.
- EN: **Where and when does flash appear?** Check mold interfaces first, then distinguish filling from packing before changing the process.

여기서 플래시·버는 금형 경계 밖으로 밀려 나온 여분의 얇은 수지다. 단순 이젝터 눌림 자국, 취출 중 찢어진 가장자리, 게이트 절단 잔여물은 모양이 비슷해도 다른 분기로 분류한다. 사진만으로 발생 시점을 판정하지 않으며, 시점을 모를 때는 “아직 모름”을 유지한다.

## 원문에서 해결 방향으로

아래 `F01` 등은 공정 처방의 우선순위나 원인 확률이 아니라 화면 분기용 식별자다. 확인·조치·채택 기준은 원문 메커니즘을 앱에 적용한 **조건부 엔지니어링 종합**이다.

| 분기·관찰 | 먼저 확인 | 확인되었을 때의 조치 | 변경 후 함께 볼 결과 | 근거·범위 |
|---|---|---|---|---|
| **F01 · 같은 파팅 라인에 반복** | 이물, 접촉 불량, 맞춤면 손상·마모, 지지 및 정렬 | 정지·격리 후 승인된 청소·접촉 확인. 손상·변형은 금형 정비로 연결 | 동일 위치 버, 금형 접촉·변형, 정상 취출 | S1, S2, S6. 일반 금형 근거; 위치만으로 손상 확정 불가 |
| **F02 · 벤트 끝에 얇은 날개** | 실제 버가 배기 홈과 일치하는지, 벤트 랜드·깊이·오염·수리 이력 | 원래 승인된 형상과 비교하여 복구. 배기 홈을 무조건 더 깊게 파거나 막지 않음 | 버뿐 아니라 말단 쇼트·가스 탄 자국·기포 | S2, S6. 배기 능력과 수지 누출의 균형; PHA 공통 깊이 없음 |
| **F03 · 이젝터 핀 둘레의 고리** | 단순 핀 자국인지 실제 얇은 수지인지, 핀/슬리브·홀의 마모·끼워맞춤 | 금형 담당자가 간극과 작동을 함께 검토. 클램프 힘만 높여 국부 간극을 숨기지 않음 | 고리 버, 핀 끼임·취출 자국, 제품 손상 | S7. 부품 간극의 버/미끄럼 상충 근거; 카탈로그 치수를 PHA 규격으로 전용하지 않음 |
| **F04 · 충전만 비교해도 버 발생** | 충전 형상·샷량·V/P 전환·말기 속도, 먼저 찬 캐비티, 국부 틈새 | 금형 이상을 배제한 뒤 과충전·말기 압력 피크를 겨냥한 제한 비교 | 전체 캐비티의 충전, 버, 실제 압력·쿠션 | S1, S3, S4. 충전 단계에서 생긴 버를 보압 감소만으로 해결하지 않음 |
| **F05 · 충전만 할 때는 없고 보압 후 발생** | V/P 전환 전 충전 상태, 전환 순간 압력 응답, 보압 전달·게이트 씰 | 늦은 전환이나 과도한 보압이 확인되면 해당 항목만 조정 | 버, 캐비티별 중량·치수, 싱크·내부 공극 | S2, S3, S5, S10. 고정 P1/P2 비율이나 공통 보압시간을 추천하지 않음 |
| **F06 · 일부 캐비티 버 + 다른 캐비티 쇼트** | 캐비티별 충전/중량 지도, 러너·게이트·온도·배기 균형과 V/P 응답 | 국부 저항·열 불균형을 확인하고 해당 원인 수정. 전체 사출압만 올리는 해결을 피함 | 평균 중량과 별도로 각 캐비티의 버·쇼트·치수 | S5. 다수 캐비티에서 전환 압력 응답이 영향을 주지만 제어 조정이 금형 균형 검토를 대신하지 않음 |
| **F07 · 잘 되다가 갑자기 또는 가열 후 증가** | lot·배합·재생재·수분, 실제 용융온도·체류, 설정/센서 변화, 금형 오염 | 확인된 재료·열 이력·계측 이상부터 복구. 필요 시 같은 조건의 MFR/MI 비교 | 버·충전과 MI, 변색·취성·제품 물성 | S1, S3, S8 및 기존 PHA 열화 조사. MI 변화 하나로 열분해를 확정하지 않음 |
| **F08 · 형체력이 부족한 듯 보임** | 전체 투영면적, 캐비티 압력 분포, 금형 지지·정렬, 실제 형체력·설비/금형 한도 | 필요한 형체 기능을 한도 안에서 검증. 계산값 또는 최대 톤수를 그대로 적용하지 않음 | 버, 금형 미세 벌어짐, 가스 탄 자국·마모 | S2, S6, S9. 높은 형체력이 항상 유리하지 않음 |

**분해·접촉면 점검은 장비의 정지·격리 절차에 따른다.** 충전만 비교하는 시험도 해당 장비에서 승인된 시험·취출 절차로 수행하며 금형 보호 기능을 유지한다. 손상된 밀봉면이나 끼인 제품이 의심되면 운전 조건을 더 밀어붙이는 대신 정비로 전환한다.

## 온도 방향은 원인에 따라 달라진다

S1의 같은 플래시 표에도 서로 다른 온도 방향이 있다. 높은 충전/보압 캐비티 압력에는 용융온도 조정·조기 전환·말기 감속을 검토하고, 과열·긴 체류·수분에 따른 낮은 점도에는 열 이력 감소를 검토한다. **“버 → 전체 배럴 감온” 또는 “압력 높음 → 승온”을 자동 연결하면 안 된다.**

| 확인한 상태 | 앱에 표시할 방향 | 채택 조건 |
|---|---|---|
| 용융·유동 부족으로 높은 충전 저항이 확인됨 | 그레이드 범위 안에서 필요한 열 공급 또는 충전 방식을 비교. 배럴 설정과 실제 수지온도를 구분 | 필요한 충전이 개선되고 버·분해·품질 문제가 늘지 않음 |
| 낮은 점도와 과열·장시간 체류·수분 문제가 함께 확인됨 | 실제 온도·회복 과정·체류·건조를 원인별로 복구. 이미 손상된 재료를 단순 냉각으로 정상화했다고 보지 않음 | 같은 시험조건의 MI와 제품 물성·외관이 기준 유지 |
| 손상된 파팅 면·과도한 국부 간극 | 온도 처방 대신 금형 수리·정합 검토 | 승인된 간극·접촉 상태 복구 후 제품 검증 |

이 표는 S1과 PHA 자료를 대조한 조건부 종합이다. 특정 온도 아래라면 분해가 없다는 보장은 없으며, 버를 줄이는 동안 미충전·싱크·표면 전사·후수축이 나빠지는지 함께 확인한다.

## 형체력 계산의 수학과 화면 문구

일반 단일 파팅 면 금형에서 분리력은 **같은 시점의 압력을 투영면적에 대해 적분한 힘**이다. 충전 또는 보압 중 그 힘이 가장 커지는 시점을 검토한다[S9]. 시간 평균압력, 한 센서의 국부 최대압력, 기계 유압을 곧바로 면적 평균 캐비티 압력으로 쓰지 않는다.

```text
F_sep(t) = integral over projected area of p(x, y, t) dA
F_peak = max over filling and packing of F_sep(t)

1 bar × 1 cm² = 10 N
1 metric tf = 9806.65 N

F_sep[tf] = P_area_average[bar] × A_projected[cm²] / 980.665
P_area_average[bar] = F_available[tf] × 980.665 / A_projected[cm²]
```

범위와 해석:

- 일반 금형은 같은 분리 방향에 작용하는 캐비티와 러너의 투영면적을 포함한다[S12]. 슬라이드·언더컷·스택 금형의 중복 투영과 여러 분리 방향은 별도 검토하며 단순 합계를 강제하지 않는다[S9].
- 출력은 **금형 분리력 / Mold separating force** 또는 **입력한 형체력으로 환산한 면적 평균 캐비티 압력 / Equivalent area-averaged cavity pressure**다. 사출기 수지압·유압 설정, 러너 보호 상한, 플래시 방지 보증이 아니다.
- 사용자가 형체력 이용률을 입력할 때는 `0 < utilization ≤ 1`을 적용한다. 여유를 “자동 +20%”로 정하지 않는다. 금형 강성·편심·압력 분포·기계 상태와 실제 제품을 검토한다.
- mm²↔cm², MPa↔bar, metric tf↔US short ton-force를 섞지 않는다. `1 MPa = 10 bar`, `1 cm² = 100 mm²`다.

현재 `process-evidence.js`를 직접 실행한 단위 확인:

| 검산 | 현재 계산 결과 | 해석 |
|---|---|---|
| 980.665 bar × 1 cm² | 1 tf | 환산 상수 확인 |
| 500 bar × 200 cm² | 101.9716213 tf | 계산 예시이며 생산 추천값 아님 |
| 100 tf × 이용률 0.8 / 200 cm² | 392.266 bar | 면적 평균 캐비티 압력 환산 예시; 기계 설정값 아님 |

## 충전·보압 비교의 함정과 확인 순서

1. 먼저 부품의 **버 위치와 캐비티 번호**를 표시한다. 위치·발생 단계를 모르면 추정으로 채우지 않는다.
2. 승인된 충전만 비교하는 시험과 정상 보압품을 비교한다[S3]. 충전 형상·쿠션·압력 응답을 같이 본다. 냉각 후 중량 비율은 압축성·게이트 역유출의 영향으로 전환 순간 체적 충전율과 같지 않을 수 있다[S4].
3. 충전 품질이 맞으면 V/P 전환 압력 응답과 보압을 구분해서 시험한다. 너무 이른 전환은 박육 말단을 동결시킬 수 있어 “무조건 조기 전환”을 피한다[S4, S5].
4. 열 게이트의 보압시간은 동일 조건에서 시간별 질량/치수와 가능한 게이트 근처 압력으로 게이트 씰을 확인한다[S10]. 밸브 게이트는 기계적 개폐 시점을 별도로 확인한다[S14]. 중량이 일정해졌다는 사실 하나로 모든 캐비티의 내부 공극·치수가 합격한 것은 아니다.
5. 한 변수씩 비교하되 버·쇼트·싱크·기포·캐비티별 중량·치수·취출·PHA 물성을 함께 판정한다. 허용치와 반복 수는 제품 규격·시험 반복성·현장 검증 계획에서 정한다.

RJG의 특정 충전율·시험 압력과 Autodesk의 보압비/기계 이용률 예시는 고정 PHA 조건으로 채택하지 않았다. 사출기 제어 방식과 형상에 따라 충전·보압·유지 단계의 구분도 달라진다.

## 현 코드와 연결할 때 수정할 문구

읽은 범위: `docs/ALL_PROCESSING_REVIEW_20260906.md`, 2026-09-06 완료 Pro 답변의 사출·플래시 행, `index.html`의 Flash 템플릿·로그 추천 엔진, `process-evidence.js`의 형체력/압력 계산. 이전 Pro 답변은 이번 새 조사를 대신하는 1차 출처로 쓰지 않았다.

- `자동 권장값 산출`, `Runner Protection Cap`, `P1/P2 Auto-Split`은 현재 계산 의미보다 강하다. 입력값의 환산·조건부 점검으로 바꾼다.
- 로그 매뉴얼의 고정 압력·온도·속도·시간 경계와 고정 증분은 현재의 조건부 엔진 및 이 조사와 맞지 않는다. 출처 없는 공통 규칙을 제거한다.
- 충전만 비교/보압 후/시점 모름과 파팅 라인/벤트/이젝터/위치 모름을 독립 선택으로 둔다. 사진 선택이 원인 확정으로 바뀌지 않게 한다.
- 벤트 개념도를 사출 금형 배기 홈과 압출기 대기·진공 포트로 혼용하지 않는다. 사출 금형의 벤트는 금형에 갇힌 가스를 배출하는 작은 통로다.
- 온도·속도·보압 변경 후의 성공 기준은 버 감소와 제품 규격 유지다. “3–5샷이면 검증 완료” 같은 고정 승인 조건을 만들지 않는다.

연구를 바탕으로 `flash-guide-data.js`에 한영 조건부 안내를 작성했다. `inspect`, `fill`, `pack`, `parting`, `vent`, `ejector`, `heat`, `resistance`의 8개 분기와 그레이드 메모·체크리스트·용어를 제공한다. 각 분기는 `when → check → action → verify → stop`과 출처를 갖는다. 위 표의 사례 분류와 런타임 분기 ID는 같은 이름 체계가 아니며, 위치와 단계 조합을 UI가 선택한다.

UI·시험 코드는 수정하지 않았으며 생산설비 조작, 신규 외부 모델 요청, 커밋·푸시를 수행하지 않았다.

검증: `node --check flash-guide-data.js` 통과. 브라우저 전역/Node 내보내기 일치, 8개 분기 ID, 한영 필수 필드, 13개 출처의 유효 참조·미사용 출처 없음, 그레이드 메모 3개·체크리스트 고유 ID 7개·용어 6개, 임의 수치 처방 부재를 직접 계약 검사로 확인했다(`FLASH_GUIDE_CONTRACT_OK`). UI 표시·선택·모바일 검증과 현장 공정 검증은 이 데이터 검사에 포함되지 않는다.
